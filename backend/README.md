# Backend

Pasta reservada para a API da Lanchonete do Pimentel.

Quando o backend for implementado, ele poderá cuidar de:

- autenticação de usuários;
- cadastro de produtos;
- armazenamento dos pedidos;
- atualização dos pedidos da cozinha;
- integração com banco de dados.

Atualmente, os dados do site são mantidos no `localStorage` pelo frontend.

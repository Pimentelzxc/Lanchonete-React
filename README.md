# Lanchonete do Pimentel

O projeto está separado em duas áreas:

- `frontend/`: páginas HTML, estilos, scripts, imagens e componentes da interface;
- `backend/`: pasta destinada à futura API e ao banco de dados.

## Executar o frontend

```bash
cd frontend
npm run dev
```

## Gerar a versão de produção

```bash
cd frontend
npm run build
```
